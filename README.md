# hands-on-JPY

日本の貨幣を画面に置き、囲んで両替することで、十進位取り記数法と
加減の繰り上がり／繰り下がりを扱う小学校算数の教具。

- 要件定義：[docs/requirements.md](docs/requirements.md)
- 本体：`src/app.html`（正本）→ `./build.sh` で `index.html` を生成
- 単体HTML・外部依存なし・ログイン不要・保存なし（教師画面のみ保存あり）

## URL パラメータ（設定画面は持たない）

| パラメータ | 値 | 既定 | 意味 |
|---|---|---|---|
| `b` | `field` / `chart` | `field` | ひろば（自由配置）／位取り表 |
| `g` | `1` / `2` / `3` | `3` | 1年=〜100円、2年=〜1000円、3年=〜10000円 |
| `size` | `s` / `l` | `s` | 児童端末／電子黒板 |
| `sum` | `1` | オフ | 総額を表示する |
| `t` | `1` | オフ | 教師画面（保存ボタンを出す） |
| `d` | — | — | 保存された盤面 |

### よく使う組み合わせ

| 用途 | URL |
|---|---|
| 2年 児童用（ひろば） | `?g=2` |
| 2年 電子黒板・教師用 | `?g=2&size=l&t=1` |
| 2年 位取り表（筆算の繰り下がり） | `?b=chart&g=2&size=l&t=1` |
| 3年 万の位 | `?b=chart&g=3&size=l&t=1` |

## 開発

```sh
./build.sh          # src/app.html → index.html
```

`src/app.html` だけを編集する。`index.html` は生成物。
