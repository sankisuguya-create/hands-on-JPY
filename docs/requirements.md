# hands-on-JPY 要件定義

日本の貨幣（1円〜10000円）を画面上に配置し、囲んで両替・操作することで、
十進位取り記数法と加減の繰り上がり／繰り下がりを扱うための教具サイト。

---

## 0. 設計の核（これが崩れると全体が崩れる）

### 0-1. 「お金」と「十進位取り」は同型ではない

十進位取り記数法は **各位が10倍ごと・各位の表現が一意** であることが本質。
一方、日本の貨幣は 1, 5, 10, 50, 100, 500, 1000, 5000, 10000 の**五二進構造**で、
同じ金額に複数の表現が存在する（例: 10円 = 10円玉1 = 5円玉2 = 1円玉10 = 5円玉1+1円玉5）。

したがって本サイトは**金種セットを切り替えられること**を必須要件とする。

| セット | 金種 | 用途 |
|---|---|---|
| **十進セット** | 1, 10, 100, 1000, 10000 | 位取り・筆算の指導。表現が一意になり、繰り上がり＝「10集めて1つ上へ」だけになる |
| **実貨幣セット** | 全9金種 | 買い物・支払い・多様な表し方の比較。そろばんの五玉と同型の構造を扱える |

既定は**十進セット**。実貨幣セットは教師が明示的に切り替える。
「5円玉があるから10のまとまりが作れない／作り方が複数ある」という混乱は、
位取りを教える場面では学習上の妨げにしかならない。

### 0-2. 扱う金種の上限は学年で切る

| 学年 | 上限 | 学習指導要領上の対応（平成29年告示） |
|---|---|---|
| 1年 | 100円まで | 20までの数・100までの数、10のまとまり、繰り上がりのある加法 |
| 2年 | 1000円まで | 1000までの数、十進位取り記数法、加減の筆算 |
| 3年 | 10000円まで | 万の単位、大きな数の加減 |
| 4年以上 | 10000円まで | 10倍・1/10の関係、概数の導入前の量感 |

金種パレットは上限までしか表示しない。
「使わない金種が見えている」こと自体が低学年の認知的負荷になる。

> 注記：現行の学習指導要領で「金銭」は算数科の内容として明示されていない。
> 貨幣はあくまで**十進位取りを扱うための具体物**として位置づける。
> 本サイトは金銭教育（生活科・家庭科）の教材ではない。

### 0-3. 貨幣は簡略図案で描く（写実的に描かない）

通貨及証券模造取締法・紙幣類似証券取締法により、
紙幣・貨幣に紛らわしい外観の複製物の作成は制限される。
教材であっても写実的な画像・スキャン画像は使わない。

**採用する図案**：
- 硬貨＝単色の円（1円は銀・5円は真鍮色など実物の色相のみ踏襲）＋中央に算用数字＋「円」
- 5円玉・50円玉は中央に穴を表す白丸を置く（実物との対応の手がかり）
- 紙幣＝角丸長方形＋数字。肖像・模様は描かない

**トレードオフ（教師が理解しておくべき点）**：
図案化により実物との転移は弱まる。実物の貨幣（またはレプリカ）を触る活動は
このサイトでは代替できない。本サイトが担うのは**両替操作の反復と可視化**であって、
貨幣の識別ではない。

## 1. 目的

1. 10のまとまりを作る／崩す操作を、児童が何度でもやり直せる形で提供する
2. 加減の筆算における繰り上がり・繰り下がりに、操作としての意味を与える
3. 教師が電子黒板上で、児童の考えを即座に盤面として再現できるようにする

## 2. 非目標（作らないもの）

- 課題・ミッション機能、正誤判定、得点、タイマー
- 児童の解答の保存・集約・提出（worksheet-platform の役割）
- ログイン、アカウント、名簿
- おつりの計算・レジのシミュレーション
- 硬貨の識別を目的とした写実的表現

理由：盤面は「教師が出した課題を映す白紙」であり続けるほうが、単元をまたいで使い回せる。
課題を内蔵すると課題データの設計と正誤判定の仕様が増え、かつ
同一金額に複数の正解がある本教材では判定が破綻しやすい。

## 3. 利用環境の制約

| 項目 | 条件 |
|---|---|
| 児童端末 | CZ1104FM2A-NS0181（メモリ8GB）／NS0254（メモリ4GB・LTE）。Chromebook、タッチ対応 |
| 教師端末 | 校務PC＋電子黒板への投影 |
| ネットワーク | LTE個体あり。初回読込後は通信不要であること |
| 配布形態 | 単体HTML 1ファイル。GitHub Pages。ログイン不要、URLのみで開く |
| 保存 | なし。リロードで盤面は消える（この挙動を画面上で明示する） |

**帰結する実装制約**：
- 外部CDN・フォント・ライブラリへの依存をゼロにする（LTE回線と校内フィルタで落ちる）
- 画像ファイルを持たない。貨幣はすべてCSS/インラインSVGで描画
- メモリ4GB端末を基準に、盤面のDOM要素数を抑える（§7参照）

## 4. 中核モデル

### 4-1. 両替規則

| 方向 | 十進セット | 実貨幣セット |
|---|---|---|
| まとめる | 1円×10 → 10円×1（各位で同様） | 上記に加え、1円×5 → 5円×1／5円×2 → 10円×1（各位で同様） |
| 崩す | 10円×1 → 1円×10（各位で同様） | 上記に加え、5円×1 → 1円×5／10円×1 → 5円×2 |

- 囲いの中身が規則に**一意に当てはまるときだけ**両替ボタンが押せる状態になる
- 実貨幣セットで複数の両替が可能なとき（例：1円が10枚 → 10円1枚 or 5円2枚）は、
  選択肢を提示する。自動で選ばない
- 両替前後で盤面の総額は必ず等しい（不変条件）

### 4-2. 囲い（選択）

囲いは**一時的な選択状態**であり、盤面に残る枠ではない。
ラベルを付けて残す機能は持たない（グループ管理は教師の板書が担う）。

囲いに対してできること：
- 両替する（まとめる／崩す）
- まとめて動かす
- まとめて複製する
- まとめて消す

## 5. 機能要件

| ID | 要件 | 優先 |
|---|---|---|
| F-01 | 金種パレットから**タップで**盤面に1枚置く | 必須 |
| F-02 | 置いた貨幣をドラッグで動かす | 必須 |
| F-03 | 矩形ドラッグで複数枚を囲う。個別タップでの追加・解除も可 | 必須 |
| F-04 | 囲いの中身をまとめる（上位金種へ） | 必須 |
| F-05 | 囲いの中身を崩す（下位金種へ） | 必須 |
| F-06 | 囲いをまとめて移動／複製／削除 | 必須 |
| F-07 | 取り消し（Undo）。最低10手 | 必須 |
| F-08 | 盤面を空にする（誤操作防止に確認を挟む） | 必須 |
| F-09 | 金種セット切替（十進／実貨幣） | 必須 |
| F-10 | 学年による上限金種の切替 | 必須 |
| F-11 | 表示モード切替（提示用／児童用） | 必須 |
| F-12 | 盤面の総額表示のオン・オフ。**既定はオフ** | 必須 |
| F-13 | 自動整列（重なった貨幣を格子状に並べ直す） | 推奨 |
| F-14 | やり直し（Redo） | 任意 |

**F-12 を既定オフにする理由**：総額が常に見えていると、児童は数えずに読む。
「いくらになったか」は児童が考える対象であって、画面が答える対象ではない。
一方、両替が金額を変えないことの確認には有効なので、教師が出せるようにする。

**両替時の扱い（F-04/F-05）**：総額表示がオフでも、両替の瞬間だけは
「変わっていない」ことが見て取れる必要がある。囲いの中身が上位金種へ
集まる過程をアニメーションで見せ、消えて現れる形にはしない。

## 6. UI要件

### 6-1. 共通

- 画面に常時出す操作は **8個以内**。それを超えるものは設定に隠す
- 文字は指示ではなく名詞で書く（「10円玉をつくる」ではなく「まとめる」）
- 押せないボタンは消さずに淡くする（位置が動くと探し直しになる）
- 誤操作は必ずUndoで戻せる。確認ダイアログは「ぜんぶ消す」のみ

### 6-2. 提示モード（電子黒板）

- 貨幣の直径を児童モードの1.5倍以上
- 教室後方から読める文字サイズ（貨幣上の数字は貨幣直径の40%以上）
- 操作パネルは画面端に寄せ、盤面を最大化
- 教師の手が画面を覆うため、重要な表示は上端に置かない

### 6-3. 児童モード

- タップ主体。ドラッグはできるが、ドラッグなしでも全操作が完結すること
- タップ対象は48px四方以上を確保
- 囲いの矩形は指を離した時点で確定。フリーハンドの投げ縄は採用しない（誤爆が多い）

## 7. 非機能要件

| 項目 | 基準 |
|---|---|
| 盤面の最大枚数 | 200枚。超過時は新規配置を止め、理由を表示する |
| 1金種あたりの上限 | 30枚（10枚で両替できるため、これで足りる） |
| 初回読込 | メモリ4GB端末・LTEで3秒以内 |
| ファイル構成 | HTML 1ファイル、外部依存なし |
| 操作の応答 | タップから描画変化まで100ms以内 |
| 色 | 金種の識別を色だけに頼らない。数字を必ず併記する（色覚特性への対応） |
| 印刷 | 盤面をA4横1枚で印刷できる（板書・ノート貼付用） |

## 8. 未決事項

1. **1円玉10枚を並べる配置の初期規則** — 自動で10ずつの列に並べるか、
   置いた位置のままにするか。前者は「10のまとまり」を画面が先に作ってしまう。
   既定は後者（置いた位置のまま）とし、F-13の整列は教師の操作で行う。
2. **提示モード／児童モードの切替をURLパラメータにするか画面上のスイッチにするか** —
   児童が誤って提示モードに入ると操作しづらくなる。URLを分ける案を推す。
3. **実貨幣セットでの「2000円札」の扱い** — 流通量が少なく、位取り指導上も雑音になる。
   現時点では含めない。
