# hands-on-JPY 要件定義 v2

日本の貨幣を画面上に置き、囲んで両替することで、十進位取り記数法と
加減の繰り上がり／繰り下がりを扱う教具。単体HTML・保存なし・ログインなし。

---

## 0. 調査でわかった、設計を決める2つの事実

### 0-1. 貨幣は「非比例型」の教具である

位取りの教具は2種類ある。

- **比例型**：10のまとまりが1の10倍の大きさで表される（ブロック、束ねた棒）
- **非比例型**：大きさと値が対応しない（お金、そろばん、色チップ）

日本の硬貨は非比例であるだけでなく、**大きさの順序と価値の順序が食い違う**。

| 硬貨 | 1円 | 5円 | 10円 | 50円 | 100円 | 500円 |
|---|---|---|---|---|---|---|
| 直径(mm) | 20.0 | 22.0 | 23.5 | 21.0 | 22.6 | 26.5 |

10円玉は500円玉に次いで大きいが、価値は3番目に低い。
50円玉は10円玉より小さいのに5倍の価値を持つ。

**帰結（実装の決定事項）**：
本サイトでは貨幣を**すべて同じ大きさの円／角丸長方形で描く**。
実物の相対サイズは再現しない。価値は数字と色だけで示す。
実物に似せると、大きさという最も強い視覚手がかりが価値と矛盾し、妨げになる。

**帰結（指導上の位置づけ）**：
非比例型の教具は、比例型（算数ブロック、数え棒）で10のまとまりを
理解した**後**に使うべきものとされる。
したがって本サイトは、1年生の位取りの初回導入には使わない。
**ブロックで10のまとまりを理解した後の、桁の拡張と筆算の意味づけ**が主たる持ち場になる。

### 0-2. つまずきは繰り下がり、特に「崩す」に集中する

調査した指導資料が共通して挙げるつまずき：

1. 繰り下がりの手続きだけを覚え、意味を理解していない
2. 連続した繰り下がり（十の位が0の場合。100−37、302−56 など）で破綻する
3. 引けないときに上下を逆にして引く

いずれも **「1つ上の位を1つ崩して10にする」という操作の像がない** ことに帰着する。
この操作は紙の上では一瞬で、児童からは見えない。

**帰結**：本サイトの中核機能は「まとめる」ではなく **「崩す」** である。
特に**連鎖して崩せること**（100円1枚 → 10円10枚 → うち1枚を1円10枚）を
一級の要件とし、操作回数を最小にする。

## 1. 盤面を2種類に分ける

自由配置の白紙は、実は認知的負荷が高い。「どこに置くか」の判断が毎回発生し、
置いた結果がばらけて数えにくい。位取りを扱う場面では置き場が決まっているほうが軽い。

### 盤面A：位取り表（既定）

```
  まん    せん    ひゃく    じゅう    いち
 ┌────┬────┬────┬────┬────┐
 │    │    │    │    │    │   ← 各列は10枚で満杯
 │    │    │    │    │    │
 └────┴────┴────┴────┴────┘
   [1万]  [千]   [百]   [十]   [1]    ← 各列の下に、その位の金種ボタン1つ
```

- 金種は **1, 10, 100, 1000, 10000 の5種のみ**（十進セット）。5円玉等は置かない
- 列の下のボタンをタップすると、その列に1枚積まれる。**置き場を選ぶ判断が消える**
- 各列は **10枚で満杯**。11枚目は入らない → 「まとめるしかない」状況が自然に生まれる
- 一万の列だけ上限なし（それより上の金種がないため）
- 列の枚数は**数字で表示しない**。数えるのは児童の仕事

### 盤面B：ひろば

- 全9金種（1, 5, 10, 50, 100, 500, 1000, 5000, 10000）を自由な位置に置く
- 買い物、支払い、「同じ金額をいろいろな出し方で」を扱う
- 位取りの指導には使わない

**盤面AとBは別のURLで開く。画面上に切替スイッチは置かない。**

## 2. 操作（これで全部）

| 操作 | やり方 |
|---|---|
| 置く | 金種ボタンをタップ |
| 囲う | 盤面を指でなぞる（矩形）。もう一度なぞると囲い直し |
| まとめる | 囲ってから「まとめる」 |
| くずす | 囲ってから「くずす」 |
| うごかす | 囲いをドラッグ |
| けす | 囲ってから「けす」 |
| もどす | 「もどす」（Undo、20手） |

**両替規則**

| | まとめる | くずす |
|---|---|---|
| 盤面A | 10枚 → 上の位1枚 | 1枚 → 下の位10枚 |
| 盤面B | 上に加え 1円×5→5円、5円×2→10円（各位で同様） | 上に加え 5円→1円×5、10円→5円×2 |

- 盤面Bで複数の両替が成り立つときは選択肢を出す。自動で選ばない
- 両替の前後で総額は必ず等しい
- **くずすは連鎖できる**：100円玉を囲んで「くずす」→ 10円玉10枚。
  そのうち1枚を囲んで「くずす」→ 1円玉10枚。各1タップ＋囲いのみ

## 3. UI：画面に出るものを数える

### 常設（盤面Aで7個）

- 金種ボタン ×5（列の下、各1個）
- 「もどす」×1
- 「ぜんぶけす」×1

### 文脈で出るもの（囲ったときだけ、囲いのすぐ横）

- 「まとめる」… まとめられるときだけ出す
- 「くずす」… くずせるときだけ出す
- 「けす」… 常に出す

**押せないボタンは出さない（常設ボタンは淡くする、文脈ボタンは出さない）。**
常設は位置が動くと探し直しになるので消さない。文脈ボタンは元々位置が動くので消してよい。

### 画面に出さないもの

- 総額、各列の枚数、式、正誤、得点、タイマー、進捗
- 設定画面、モード切替、学年選択（すべてURLで決める）
- メニュー、ヘルプ、説明文

**総額を出さない理由**：総額が見えていると児童は数えずに読む。
いくらになったかは児童が考える対象であって、画面が答える対象ではない。
教師が必要とする場面のために、URLパラメータで出せるようにはしておく（既定はオフ）。

### 文言

- 児童向けの文字は**すべてひらがな**（1〜2年で漢字が読めないため）
- ボタンは動詞1語（「まとめる」「くずす」「けす」「もどす」）。説明を添えない
- 位の名前だけは盤面Aの列見出しに出す（「まん／せん／ひゃく／じゅう／いち」）

### 両替の見せ方

「まとめる」を押した瞬間、囲った10枚が**一列に並んでから**1枚に変わる。
消えて現れる形にしない。
総額を出さない設計なので、金額が変わっていないことを伝える手段はこのアニメーションだけになる。
「くずす」は逆再生。

## 4. URLで決めること（設定UIを持たない）

| パラメータ | 値 | 既定 |
|---|---|---|
| `b`（盤面） | `chart`（位取り表）／`field`（ひろば） | `chart` |
| `g`（学年） | `1`＝一・十／`2`＝一〜千／`3`＝一〜万 | `3` |
| `size`（大きさ） | `s`（児童端末）／`l`（電子黒板） | `s` |
| `sum`（総額） | `1` で表示 | オフ |

教師は用途別のURLをブックマークし、児童にはその日使うURLだけを渡す。
児童の画面に設定が現れないので、誤って別モードに入る事故が起きない。

## 5. 学年と単元の対応

| 学年 | 盤面 | 使いどころ |
|---|---|---|
| 1 | A（一・十） | ブロックで10のまとまりを学んだ**後**。繰り上がりのある加法の意味づけ |
| 2 | A（一〜千） | 1000までの数、加減の筆算。**繰り下がりの「崩す」が主戦場** |
| 2 | B | 買い物の場面、同じ金額のいろいろな表し方 |
| 3 | A（一〜万） | 万の単位、大きな数の加減 |
| 3 | A | 数の相対的な大きさ（350は10を35個集めた数）※§7-1参照 |
| 4 | A | 10倍・1/10の関係 |

現行の学習指導要領（平成29年告示）で「金銭」は算数科の内容に明示されていない。
貨幣は十進位取りを扱うための具体物という位置づけであり、
本サイトは金銭教育（生活科・家庭科）の教材ではない。

## 6. 制約

| 項目 | 条件 |
|---|---|
| 端末 | Chromebook CZ1104FM2A（4GB／8GB、タッチ、LTE個体あり） |
| 配布 | 単体HTML 1ファイル、GitHub Pages、ログイン不要 |
| 外部依存 | ゼロ。CDN・Webフォント・画像ファイルを使わない（LTEと校内フィルタで落ちるため） |
| 貨幣の描画 | CSS／インラインSVGのみ。実物画像・写実的図案を使わない（通貨及証券模造取締法） |
| 保存 | なし。リロードで消えることを画面下に1行だけ書く |
| 盤面の最大枚数 | 200枚 |
| タップ対象 | 48px四方以上 |
| 応答 | タップから描画変化まで100ms以内 |
| 色 | 金種を色だけで区別しない。数字を必ず併記する |
| 印刷 | 盤面をA4横1枚で印刷できる |

**貨幣の図案**：硬貨＝単色の円＋算用数字（5円・50円は中央に白丸で穴を表す）、
紙幣＝角丸長方形＋算用数字。肖像・模様は描かない。すべて同じ大きさ（§0-1）。
図案化により実物との転移は弱まる。実物を触る活動の代替にはならない。

## 7. 判断待ち

### 7-1. 「1種類の金種だけで表す」ボタンを入れるか

3年の「数の相対的な大きさ」（350は10を35個集めた数）は、貨幣が例外的によく表せる内容。
「ぜんぶ10円玉にする」ボタンがあれば、350円 → 10円玉35枚が一動作で見える。

- 入れる利点：教科書のこの内容に他の教具では届きにくい
- 入れない利点：ボタンが1つ増える。かつ「くずす」を繰り返せば手作業でも到達できる

### 7-2. 盤面Aの列が満杯になったときの挙動

- 案1：11枚目が入らない。無言で拒む
- 案2：11枚目が入らず、列が一瞬光る
- 案3：11枚目を置くと自動でまとめる

案3は繰り上がりを画面が代行してしまうので採らない。案1と案2の差は、
児童が「なぜ置けないのか」を自力で気づくか、気づく手がかりを与えるか。

### 7-3. 囲いのジェスチャ

矩形ドラッグを既定とする。ただし盤面Aは列構造があるため、
「列をタップして列ごと囲う」ほうが速く、誤操作もない可能性がある。
低学年で矩形ドラッグが実用に耐えるかは、実機で確かめる必要がある。
