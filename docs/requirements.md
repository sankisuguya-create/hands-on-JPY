# hands-on-JPY 要件定義 v3

日本の貨幣を画面上に置き、囲んで両替することで、十進位取り記数法と
加減の繰り上がり／繰り下がりを扱う教具。単体HTML・ログインなし。児童は保存なし、教師はURLと画像で保存できる。

---

## 0. 調査でわかった、設計を決める2つの事実

### 0-1. 貨幣は「非比例型」の教具である

位取りの教具は2種類ある。

- **比例型**：10のまとまりが1の10倍の大きさで表される（ブロック、束ねた棒）
- **非比例型**：大きさと値が対応しない（お金、そろばん、色チップ）

日本の硬貨は非比例であるだけでなく、**大きさの順序と価値の順序が食い違う**。

| 硬貨 | 1円 | 5円 | 10円 | 50円 | 100円 | 500円 |
|---|---|---|---|---|---|---|
| 直径(mm) | 20.0 | 22.0 | 23.5 | 21.0 | 22.6 | 26.5 |

10円玉は500円玉に次いで大きいが、価値は3番目に低い。
50円玉は10円玉より小さいのに5倍の価値を持つ。

**帰結（実装の決定事項）**：
本サイトでは貨幣を**すべて同じ大きさの円／角丸長方形で描く**。
実物の相対サイズは再現しない。価値は数字と色だけで示す。
実物に似せると、大きさという最も強い視覚手がかりが価値と矛盾し、妨げになる。

**帰結（指導上の位置づけ）**：
非比例型の教具は、比例型（算数ブロック、数え棒）で10のまとまりを
理解した**後**に使うべきものとされる。
したがって本サイトは、1年生の位取りの初回導入には使わない。
**ブロックで10のまとまりを理解した後の、桁の拡張と筆算の意味づけ**が主たる持ち場になる。

### 0-2. つまずきは繰り下がり、特に「崩す」に集中する

調査した指導資料が共通して挙げるつまずき：

1. 繰り下がりの手続きだけを覚え、意味を理解していない
2. 連続した繰り下がり（十の位が0の場合。100−37、302−56 など）で破綻する
3. 引けないときに上下を逆にして引く

いずれも **「1つ上の位を1つ崩して10にする」という操作の像がない** ことに帰着する。
この操作は紙の上では一瞬で、児童からは見えない。

**帰結**：本サイトの中核機能は「まとめる」ではなく **「崩す」** である。
特に**連鎖して崩せること**（100円1枚 → 10円10枚 → うち1枚を1円10枚）を
一級の要件とし、操作回数を最小にする。

## 1. 盤面

### 盤面A：ひろば（既定）

- 全9金種（1, 5, 10, 50, 100, 500, 1000, 5000, 10000）を自由な位置に置く
- 金種パレットは画面下端に1列。学年の上限を超える金種は表示しない
- 置いた貨幣は自由に動かせる

**自由配置にしたことで開く穴と、その埋め方**

列構造（1列=10枚で満杯）を捨てたので、「10枚たまったら繰り上がるしかない」という
必然性が盤面から消える。これを次で埋める。

> **「まとめる」は、囲いの中身がちょうど両替できる枚数のときにだけ出る。**

10枚ちょうど囲わないと「まとめる」が現れない。つまり児童は自分で数えて囲う必要がある。
位取り表が「置き場」で保証していたものを、「囲う行為」に移す。
数える手間が発生する分、位取り表より学習価値は高い。

**自動整列は入れない**

散らかった貨幣を並べ直して数えやすくするのは、1・2年の学習内容そのもの
（数え方の工夫、10のまとまりを作る）。画面が代行すると学習が消える。

ただし操作不能になる事故は防ぐ。**置いた瞬間だけ**、既存の貨幣と重ならない位置に
自動でずらす。並べ方には介入しない。

### 盤面B：位取り表（`?b=chart`）

```
  まん    せん    ひゃく    じゅう    いち
 ┌────┬────┬────┬────┬────┐
 │    │    │    │    │    │   ← 各列は10枚で満杯
 └────┴────┴────┴────┴────┘
   [1万]  [千]   [百]   [十]   [1]    ← 各列の下に、その位の金種ボタン1つ
```

- 金種は 1, 10, 100, 1000, 10000 の5種のみ。5円玉等は置かない
- 列の下のボタンをタップすると、その列に1枚積まれる。置き場を選ぶ判断が消える
- 各列は10枚で満杯。11枚目は入らない
- 一万の列だけ上限なし（それより上の金種がないため）
- 列の枚数は数字で表示しない

置き場の判断が消えるぶん負荷が低い。自由配置がうまくいかない児童・場面の逃げ道として持つ。

## 2. 操作（これで全部）

| 操作 | やり方 |
|---|---|
| 置く | 金種ボタンをタップ |
| 囲う | 盤面を指でなぞる（矩形）。もう一度なぞると囲い直し |
| まとめる | 囲ってから「まとめる」 |
| くずす | 囲ってから「くずす」 |
| うごかす | 囲いをドラッグ |
| けす | 囲ってから「けす」 |
| もどす | 「もどす」（Undo、20手） |
| ぜんぶ◯円玉にする | 囲った状態で金種パレットをタップ（3年以上のみ、§2-1） |

**両替規則**

| | まとめる | くずす |
|---|---|---|
| 盤面A | 10枚 → 上の位1枚 | 1枚 → 下の位10枚 |
| 盤面B | 上に加え 1円×5→5円、5円×2→10円（各位で同様） | 上に加え 5円→1円×5、10円→5円×2 |

- 盤面Bで複数の両替が成り立つときは選択肢を出す。自動で選ばない
- 両替の前後で総額は必ず等しい
- **くずすは連鎖できる**：100円玉を囲んで「くずす」→ 10円玉10枚。
  そのうち1枚を囲んで「くずす」→ 1円玉10枚。各1タップ＋囲いのみ

### 2-1. ぜんぶ◯円玉にする（3年「数の相対的な大きさ」用）

350は10を35個集めた数、という見方を貨幣は例外的によく表せる。
350円を囲んで10円玉をタップ → 10円玉35枚になる。

**新しいボタンを増やさない**。囲っている間だけ、金種パレットの意味が
「置く」から「囲った分をこの金種だけにする」に変わる。
囲い中はパレットに枠を付けて、意味が変わっていることを示す。

- **`g=3` 以上でのみ有効**。1・2年では「置く」との混同が事故になるため無効にする
- 割り切れないとき（350円を100円玉だけに、など）は、そのパレットを押せなくする
- 結果の35枚は自動で並べる（手で置いたものではないため、並べ方の学習を奪わない）。
  ただし**10ずつでは並べない**。10列に並べると「35は10が3つと5」を画面が教えてしまう

## 3. UI：画面に出るものを数える

### 常設（ひろば・3年で11個）

- 金種ボタン（学年の上限まで。1年=5個〈〜100円〉／2年=7個〈〜1000円〉／3年=9個）
- 「もどす」×1
- 「ぜんぶけす」×1
- 教師画面（`?t=1`）のみ、これに「URLでほぞん」「がぞうでほぞん」の2個が加わる

金種ボタンは学年で減る。3年の9個が上限で、1年は1・5・10・50・100の5個しか出ない。
**使わない金種が見えていること自体が低学年の負荷**なので、隠すのではなく出さない。

### 文脈で出るもの（囲ったときだけ、囲いのすぐ横）

- 「まとめる」… まとめられるときだけ出す
- 「くずす」… くずせるときだけ出す
- 「けす」… 常に出す

**押せないボタンは出さない（常設ボタンは淡くする、文脈ボタンは出さない）。**
常設は位置が動くと探し直しになるので消さない。文脈ボタンは元々位置が動くので消してよい。

### 画面に出さないもの

- 総額、各列の枚数、式、正誤、得点、タイマー、進捗
- 設定画面、モード切替、学年選択（すべてURLで決める）
- メニュー、ヘルプ、説明文

**総額を出さない理由**：総額が見えていると児童は数えずに読む。
いくらになったかは児童が考える対象であって、画面が答える対象ではない。
教師が必要とする場面のために、URLパラメータで出せるようにはしておく（既定はオフ）。

### 文言

- 児童向けの文字は**すべてひらがな**（1〜2年で漢字が読めないため）
- ボタンは動詞1語（「まとめる」「くずす」「けす」「もどす」）。説明を添えない
- 位の名前だけは盤面Bの列見出しに出す（「まん／せん／ひゃく／じゅう／いち」）

### 両替の見せ方

「まとめる」を押した瞬間、囲った10枚が**一列に並んでから**1枚に変わる。
消えて現れる形にしない。
総額を出さない設計なので、金額が変わっていないことを伝える手段はこのアニメーションだけになる。
「くずす」は逆再生。

## 4. URLで決めること（設定UIを持たない）

| パラメータ | 値 | 既定 |
|---|---|---|
| `b`（盤面） | `field`（ひろば）／`chart`（位取り表） | `field` |
| `g`（学年） | `1`＝一・十／`2`＝一〜千／`3`＝一〜万 | `3` |
| `size`（大きさ） | `s`（児童端末）／`l`（電子黒板） | `s` |
| `sum`（総額） | `1` で表示 | オフ |
| `t`（教師画面） | `1` で保存機能を出す（§4-1） | オフ |
| `d`（盤面データ） | 保存された盤面（§4-1） | なし |

教師は用途別のURLをブックマークし、児童にはその日使うURLだけを渡す。
児童の画面に設定が現れないので、誤って別モードに入る事故が起きない。

### 4-1. 保存（教師画面のみ。`?t=1`）

保存したい理由は2つあり、必要なものが違う。両方入れる。

| | 用途 | 方式 |
|---|---|---|
| **URLで保存** | 授業前に作った盤面を、授業中に開く | 盤面を`d=`にエンコードしてURLをコピー |
| **画像で保存** | 授業中の盤面を板書・ワークシート・振り返りに残す | PNGを書き出す |

**URL保存を選ぶ理由**：ログイン不要・サーバ不要・単体HTMLを壊さずに、
端末をまたげる唯一の方法。校務PCで作ったURLをGitHubやClassroomに貼れば、
私用PC・iPhone・電子黒板のどこからでも同じ盤面が開く。
localStorageだと端末が変わった時点で消えるため採らない。

**容量の見積もり**：座標を格子に丸めて1枚あたり20bit、200枚で約500バイト、
Base64で約700文字。URL長2000文字の実用上限に収まる。

- 保存ボタンは `?t=1` のときだけ出る。児童画面には一切出ない
- `d=` 付きのURLで開いた盤面も、児童は自由に操作できる（読み取り専用にしない）

## 5. 学年と単元の対応

| 学年 | 盤面 | 使いどころ |
|---|---|---|
| 1 | B（一・十） | ブロックで10のまとまりを学んだ**後**。繰り上がりのある加法の意味づけ |
| 2 | B（一〜千） | 1000までの数、加減の筆算。**繰り下がりの「崩す」が主戦場** |
| 2 | A | 買い物の場面、同じ金額のいろいろな表し方 |
| 3 | B（一〜万） | 万の単位、大きな数の加減 |
| 3 | A | 数の相対的な大きさ（350は10を35個集めた数）※§2-1 |
| 4 | B | 10倍・1/10の関係 |

現行の学習指導要領（平成29年告示）で「金銭」は算数科の内容に明示されていない。
貨幣は十進位取りを扱うための具体物という位置づけであり、
本サイトは金銭教育（生活科・家庭科）の教材ではない。

## 6. 制約

| 項目 | 条件 |
|---|---|
| 端末 | Chromebook CZ1104FM2A（4GB／8GB、タッチ、LTE個体あり） |
| 配布 | 単体HTML 1ファイル、GitHub Pages、ログイン不要 |
| 外部依存 | ゼロ。CDN・Webフォント・画像ファイルを使わない（LTEと校内フィルタで落ちるため） |
| 貨幣の描画 | CSS／インラインSVGのみ。実物画像・写実的図案を使わない（通貨及証券模造取締法） |
| 保存 | 児童画面はなし（リロードで消えることを画面下に1行書く）。教師画面はURL・画像（§4-1） |
| 盤面の最大枚数 | 200枚 |
| タップ対象 | 48px四方以上 |
| 応答 | タップから描画変化まで100ms以内 |
| 色 | 金種を色だけで区別しない。数字を必ず併記する |
| 印刷 | 盤面をA4横1枚で印刷できる |

**貨幣の図案**：硬貨＝単色の円＋算用数字（5円・50円は中央に白丸で穴を表す）、
紙幣＝角丸長方形＋算用数字。肖像・模様は描かない。すべて同じ大きさ（§0-1）。
図案化により実物との転移は弱まる。実物を触る活動の代替にはならない。

## 7. 判断待ち

### 7-1. 盤面B（位取り表）の列が満杯になったときの挙動

- 案1：11枚目が入らない。無言で拒む
- 案2：11枚目が入らず、列が一瞬光る
- 案3：11枚目を置くと自動でまとめる

案3は繰り上がりを画面が代行してしまうので採らない。案1と案2の差は、
児童が「なぜ置けないのか」を自力で気づくか、気づく手がかりを与えるか。

### 7-2. 囲いのジェスチャ

矩形ドラッグを既定とする。盤面B（位取り表）では列タップで列ごと囲えるようにする。
低学年で矩形ドラッグが実用に耐えるかは、実機で確かめる必要がある。
耐えないなら、貨幣を1枚ずつタップして選ぶ方式に落とす。
